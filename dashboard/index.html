Connect GitHub

The control panel talks to the GitHub API straight from this browser. It needs a fine-grained personal access token for this repository.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → this repo.
  3. Repository permissions, Read and write: Actions, Contents, Issues, Pull requests. Read: Commit statuses (and Checks if listed). Metadata is added automatically.
  4. Generate the token and paste it below.

The token is stored only in this browser's localStorage and is sent only to api.github.com. Use Disconnect in Settings to remove it.
